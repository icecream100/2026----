# 金华理工二期产品原型

## 目录说明

- `index.html`
  - 二期原型总入口
- `201_告警中心.html`
  - 告警中心模块入口页
- `202_规则引擎.html`
  - 规则引擎模块入口页
- `203_设备管理.html`
  - 设备管理模块入口页，已合并设备管理仪表盘
- `204_数据处理服务管理.html`
  - 数据处理服务管理模块入口页
- `205_第三方平台管理.html`
  - 第三方平台管理模块入口页
- `206_权限申请.html`
  - 权限申请模块入口页，一期 `105` 原型并入二期
- `assets/`
  - 统一样式和脚本
- `modules/`
  - 复制后的原始模块原型页面，保持各自原有结构

## 使用方式

1. 打开任一模块入口页，如 `201_告警中心.html` 或 `206_权限申请.html`
2. 从左侧导航或模块卡片进入对应功能模块
3. 在模块入口页中选择具体原型页面

## 组织原则

- 统一左侧导航
- 统一模块页标题
- 原有原型主体内容保持不动
- 适合直接提交到 GitHub 进行静态共享
