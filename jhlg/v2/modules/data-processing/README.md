# 数据处理服务管理新增功能 原型说明

## 1. 原型简介

本原型依据《增量需求文档 - 数据处理服务管理新增功能 v1.0》生成，采用**企业微信 B 端后台风格**进行构建。核心展示了包含 5 项数据处理指标统计的仪表盘界面，以及在日志管理界面补充的日志导出能力。

**在线展现入口：**

- [仪表盘首页](index.html)
- [日志管理(支持导出)](pages/log-search.html)

## 2. 页面结构与交互体现

### 2.1 仪表盘统计模块 (`index.html`)

原型依照 PRD 建议的信息架构，以“一个总页 + 五个统计分析模块”组织：

- **公共筛选区**：支持时间粒度变更与多维度的接口/应用筛选，具有统一的 `查询`、`重置` 动作闭环与提示状态。
- **模块 1、2：访问频率与接口质量**：分别使用双折线图及渐变面积图，结合核心率值卡片进行可视化表达。
- **模块 3：支撑应用统计**：采用饼图 + Top 10排行的组合组件设计，还原了对调用接口的终端应用分布的宏观控制。
- **模块 4、5：数据量与数据质量分析**：采用了组合柱状图与阶段通过率趋势图，满足数据运维人员的日常检视诉求。

### 2.2 日志管理导出能力 (`pages/log-search.html`)

- 页面结构贴近现网截图，采用 `访问日志`、`系统日志` 双页签组织，并保留右上角 `查询`、`重置` 的操作布局。
- 在查询按钮组中新增 `导出` 功能按钮，导出对象始终限定为当前页签下的当前查询结果。
- 弹窗内提供 `CSV` 或 `Excel` 单选能力，并展示当前导出页签、结果条数和文件名预览。

## 3. 测试与验收准则覆盖

本原型已满足以下关键验收标准的结构支持：

- ✅ 数据处理服务管理下提供仪表盘入口
- ✅ 包含共享接口频率、质量、支撑应用、数据量、数据质量五个完备的图表组件
- ✅ 界面能响应访问日志 / 系统日志切换、日志详情查看和日志导出动作
