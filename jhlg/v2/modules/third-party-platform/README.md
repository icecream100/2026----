# 原型说明：第三方平台管理新增功能

本原型根据 [PRD-第三方平台管理新增功能-v1.0](../../../../prd/第三方平台管理新增功能/PRD-第三方平台管理新增功能-v1.0.md) 生成。

## 原型组成与映射

- **端形态与风格**：PC 端 / B 端后台系统风格，使用 Tailwind CSS + Alpine.js 构建。
- **模块首页：`index.html`**
  - 承载第三方平台列表、查询、启停、新增 / 编辑、赋权和 `查看API` 入口。
  - 已补齐编辑回填、服务类型联动显隐、设备多维鉴权和查询 / 重置闭环。
- **API 文档页：`pages/api_docs.html`**
  - 对应 PRD 4.6 的 `查看API` 映射交付。
  - 展示设备清单、状态、实时数据、命令控制、命令反馈等能力说明。
- **接口治理页：`pages/api_governance.html`**
  - 承载 PRD 4.4 的接口监控、接口日志记录、接口版本管理、接口性能优化。
  - 已补齐监控时间范围筛选、日志字段完整性、查询 / 重置和日志详情抽屉。
- **数据共享管理页：`pages/data_sharing.html`**
  - 承载 PRD 4.5 的服务目录管理、数据共享调用、4 类共享配置、共享统计和趋势分析。
  - 已补齐调用查询 / 重置闭环、共享配置状态字段和编辑入口。
- **API 配置页：`pages/api_config.html`**
  - 对应 PRD 4.6 的 `API配置` 映射交付。
  - 用于演示接口开放范围、认证方式、版本状态和启停配置。

## 当前说明

1. 表格及详情数据均为本地 Mock 数据，用于静态原型演示。
2. 趋势图和统计图仍使用轻量 CSS 模拟，真实开发建议替换为 ECharts。
3. 原型目标是完成需求评审与交互闭环验证，不代表最终前端实现方案。
