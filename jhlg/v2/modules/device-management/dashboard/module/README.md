# 设备管理仪表盘新增功能 原型说明

## 1. 原型简介

本原型依据《增量需求文档 - 设备管理仪表盘新增功能 v1.0》生成，采用**企业微信 B 端后台风格**，核心展现了设备管理仪表盘在全局统计分析与实时监测维度的 12 项新增能力。原型基于 Tailwind CSS + ECharts 构建，无外部依赖文件，可以直接在浏览器中双击运行。

**在线文件：** [`index.html`](index.html)

## 2. 页面结构与交互体现

为符合 PRD 要求的“一屏可总览、二屏可下钻”的设计原则，本次未拆分多级页面，而是在单页中构建了三个清晰的纵向区块：

### 2.1 全局筛选与概览区 (顶部 & 第 1 屏)

- **全局筛选区**：支持时间范围、关联维度的筛选切换，提供了 JS 模拟下的`重置/查询`反馈，全局查询动作会触发轻量化的 Toast 提示。
- **概览卡片区**：不仅展示设备数、产品数、消息量，还增加了“在线率趋势条”和“相比上一周期”的微小增长标识，强化管理态势直觉。

### 2.2 统计分析区 (第 2 屏)

- 以横向 Tabs 组织了“离在线、告警、感知数据、控制、运维、综合分析”六大业务维度。
- 为“离在线统计”和“设备告警统计”接入了逼真的拟态 ECharts 图表，支持响应式 Resize。
- **综合分析**：点击后提供次级页签（Sub-Tab），对应实现了“设备属性分布”和“治理人员工作量排行榜”的交互切换和表格展示。
- 其他 Tab 预留了友好的骨架占位态。

### 2.3 实时监测区 (第 3 屏)

- 定位为每 60 秒刷新的流动列表，采用网格化 (Cards Grid) 布局平行铺设了设备的多种运行监测面。
- 重点绘制了**设备控制监测**、**流量监测**（含异常标红体验）、**API调用接口监测**。同时为未展开项（平台推送、共享数据、接入监测）补充了统一设计规范的空白骨架。

## 3. 测试与验收准则覆盖

本原型已满足以下关键验收标准支持，可供下述指令校验：

- ✅ 页面包含概览区、统计分析区、实时监测区三个大区块
- ✅ 全局筛选联动设计体现
- ✅ 各子分析项（告警、感知、运维、离在线等）入口齐备并配有业务占位符
- ✅ “综合统计分析”提供人员工作量与设备属性双重视图
- ✅ 状态反馈机制可用（Toast 提示加载，图表无白屏交互）
