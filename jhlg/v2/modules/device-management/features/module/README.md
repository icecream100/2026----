# 设备管理新增功能原型说明

## 1. 原型生成概况

根据 `PRD-设备管理新增功能-v1.0.md` 需求文档生成的 HTML 高保真原型，包含了 PRD 中所有新增页面、修改字段和交互闭环。

- **原型组织方式**：多页面关联结构
- **UI 设计系统**：企业微信/B端管理后台风格
- **基础技术栈**：HTML5 + Tailwind CSS + Vanilla JS + Phosphor Icons
- **响应尺寸**：PC 端 1440px 桌面端布局优先

## 2. 页面与功能覆盖地图

原型目录位于：`/Users/wangjingang/Library/Mobile Documents/iCloud~md~obsidian/Documents/alex/claudecode/pmtools/prototype/设备管理新增功能/`

### 2.1 主入口：设备列表 (`index.html`)

- **功能覆盖**：
  - 列表字段补齐：展示了 `设备厂家`、`设备型号`、`设备状态`、`生命周期状态(含帮助提示)`、`最后上线时间`
  - 搜索条件补齐：包含 `生命周期状态` 与 `退役时间范围` 搜索输入控件
  - **核心交互闭环**：“操作 - 编辑/新增设备”，点击弹出**设备信息管理（右侧抽屉）**，模拟了基于原有属性的扩展（新增了“生命周期与退役提醒”页签），支持退役提醒人员和平台消息交互

### 2.2 设备详情 (`pages/device-detail.html`)

- **功能覆盖**：
  - 页面结构：沿用了详情框架，默认定位在“实例信息” Tab
  - 概况字段补齐：展示补充的 `设备服役时间`、`设备退役时间`、`最后上线时间`，并用醒目标签提示为本次新增项

### 2.3 设备开发配置 (`pages/dev-config.html`)

- **功能覆盖**：
  - 以设备组织、名称、ID查询独立清单
  - 状态字段展示：包括开关（Toggle）切换启停状态，带有完整的前端警告窗口闭环
  - 支持批量启停操作

### 2.4 感知数据目录管理 (`pages/data-catalog.html`)

- **功能覆盖**：
  - 依据设备类型展示聚合的目录卡片（如标准安防摄像头数据目录等）
  - 发布状态显隐
  - **核心交互闭环**：“操作 - 查看目录”，点击弹出**属性及事件抽屉**，详细展示提取自物模型的 identifier, 数据类型, 及来源类型（属性/事件）。同时支持快捷的停用和发布触发

### 2.5 设备组开发配置 (`pages/group-config.html`)

- **功能覆盖**：
  - 双栏标签页结构：`系统分组` vs `自定义分组`
  - 系统分组：仅展现按维度（如行业、地区等）聚合的数据结果及数量
  - 自定义分组：提供完整的 CRUD 体验
  - **核心交互闭环**：“新增自定义分组”，点击弹出**编辑抽屉**，可以手工填写分组说明、挑选/移除成员设备，并保存
