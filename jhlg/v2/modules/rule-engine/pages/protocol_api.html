03 SDK 初始化

ProtocolSdk sdk = ProtocolSdk.builder()
    .appKey("demo-app")
    .secret("******")
    .registerDefaultCodecs()
    .build();

04 解析器注册

开发者需实现 ProtocolParser 接口，并按协议类型注册。 

sdk.register("mqtt-water-meter", new WaterMeterMqttParser());

public class WaterMeterMqttParser implements ProtocolParser {
    @Override
    public ParseResult parse(ParseContext context) {
        String payload = context.getPayload();
        return ParseResult.success(Map.of("temperature", 25.3, "humidity", 63));
    }
}

05 输入报文结构

名称 标识 类型 说明 示例值
原始报文 payload String 设备上报的原始字符串或二进制转码内容 7E010203...
设备编码 deviceCode String 平台内部设备唯一编码 WM-10086
上报时间 reportTime DateTime 原始上报时间戳 2026-03-14 10:15:20

07 错误码说明

错误码 说明 处理建议
P001 报文格式不合法 检查报文头、长度位和校验位
P002 设备编码缺失 确认接入网关是否传递 deviceCode
P003 解析器未注册 校验解析器标识和注册流程

09 常见问题

Q1：是否支持多个解析器并存？

支持。平台按解析器标识加载对应实现，不同协议或不同厂家可分别注册。

Q2：示例工程是否可直接改造上线？

示例工程仅用于演示接口接入方式，生产环境需按企业规范补充配置、日志和安全控制。
