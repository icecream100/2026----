功能说明

1、平台支持将告警数据输出到 Kafka，第三方系统可订阅 Kafka 中的告警数据并进行业务处理。
2、第三方系统处理完成后，可将处理结果回传到指定 Topic，平台订阅后回写处理状态。
3、输出与输入为两套独立配置，可分别启停和维护。

输出参数

名称 标识 类型 说明 示例值
告警名称 alarmName string 推送的告警名称 烟感告警
告警编码 alarmCode string 推送的告警类型编码 16051117
告警唯一ID alarmId string 告警记录唯一主键 15159928
设备ID deviceId string 触发告警的设备标识 ba33a59c

输入参数

名称 标识 类型 说明 示例值
告警唯一ID alarmId string 对应平台输出的告警标识 15159928
处理状态 handleStatus string 第三方处理结果 已处理
处理人 handleUser string 第三方系统处理人 张三
处理说明 handleRemark string 处理备注 已通知现场核查
告警输出示例
{
  "alarmId": "15159928",
  "alarmName": "烟感告警",
  "alarmCode": "16051117",
  "deviceId": "ba33a59c"
}
处理结果输入示例
{
  "alarmId": "15159928",
  "handleStatus": "已处理",
  "handleUser": "张三",
  "handleRemark": "现场已确认"
}
