## 页面组成

- `105_需求登记.html`
  - 开发者侧权限申请入口，包含新增需求、查看详情、撤回和重新申请。
- `105_需求审批.html`
  - 管理员侧审批页面，包含待办 / 已办、通过 / 驳回和授权微调。
- `105_授权管理.html`
  - 管理员侧授权查询页面，包含授权详情和撤销授权。
- `styles.css` / `script.js`
  - 复用一期原型的公共样式和基础交互脚本，保证原有页面表现不变。
