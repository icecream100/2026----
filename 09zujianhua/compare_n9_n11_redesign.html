告警多维复合筛选 🔵 全新开发 基础时间与状态筛选。 支持状态、告警级别、告警判定（属实/误报/重复）、任务、时间范围等复合查询。 告警表建立组合索引，扩充告警分页 API 查询参数。
等级快照与分级通知 🔵 全新开发 无等级区分与差异化提醒。 告警快照任务等级并高亮着色、高危优先排序；通知渠道实现强提醒与普通提醒分级。 告警表写入任务等级快照；对接通知中心分级推送路由。

❌ 废弃与禁止链路 (研发避坑 3 大红线)
  • 1. 严禁 N9 轨迹结果一键布控： 前端彻底删除该按钮，禁止向 N11 写入目标或任务。

  • 3. 严禁数据库跨库 Join： 两组件数据必须走 HTTP API 交互，严禁跨 DB 视图或 Join。
